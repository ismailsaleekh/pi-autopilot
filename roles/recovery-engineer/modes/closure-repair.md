## Mode objective

Close one evidence gap that blocks independent validation without changing behavior unnecessarily.

## Additional context

Use the typed evidence-gap finding, original approved unit and criteria, exact candidate/base/worktree, prior delivery evidence, and original validation gate.

## Mode procedure

Verify whether evidence is truly missing, collect only focused evidence authorized by the assignment, and change source only if the evidence gap exposes an in-scope implementation defect. Preserve behavior and contracts. Use `no-defect` when the existing candidate is correct and newly bound evidence disproves the gap; route required authority or infrastructure changes with the corresponding blocked disposition.

## Mode evidence

Evidence is finding-to-action traceability, focused command output, preserved behavior, exact candidate/base identity, and same-gate revalidation identity.
