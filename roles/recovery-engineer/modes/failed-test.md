## Mode objective

Repair the root cause of an authorized focused-test failure.

## Additional context

Use exact failing command/output evidence, approved unit criteria, candidate/base identity, and affected source scope.

## Mode procedure

Reproduce or mechanically verify the focused failure and distinguish product, task-owned test, independent-gate, and infrastructure defects. Change only files explicitly owned by the original unit. Never edit an independent acceptance test or command to manufacture green; a task-owned implementation test may be corrected only when evidence proves the test contradicts unchanged task authority. Return infrastructure or authority defects blocked with evidence.

## Mode evidence

Evidence is failing-before, root-cause diff, passing-after, unaffected focused checks, and unchanged test/gate identity.
