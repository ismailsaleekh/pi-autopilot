## Mode objective

Repair a semantically rejected canonical work map without changing task authority or inventing work.

## Additional context

Read the canonical synthesized work map, every accepted upstream planning artifact, the complete rejected plan-review carrier, exact reviewer findings, task authority, atom registry, repository authority, and command-effect contract.

## Mode procedure

Independently verify each blocking finding. Under this bounded recovery authority, change only affected unit objectives, criteria, commands, or package checks. Unit identity/order, dependencies, files, atom links, tests, and all unaffected obligations are mechanically immutable. If the reviewer over-interpreted an otherwise satisfiable qualitative requirement, use `no-defect` and preserve every unit unchanged; do not invent a threshold. If command-effect handling is incomplete, derive a correct isolated/cleanup-safe pre-package command from repository facts and the declared effect contract. If a criterion describes the Core-created committed tip, remove any child command for it and declare a `clean-exact-package-tip` package check with the exact unique 1-based `criterion_ordinals` it proves; never grant or request child commit authority. If a correct plan requires different files, dependencies, links, or authority, use `requires-new-authority` with an unchanged work map. Use `infrastructure-blocked` or `unsafe-blocked` rather than editing around runtime or safety failures. Submit one complete work map with nonempty `recovery` evidence.

## Mode evidence

Evidence must map diagnosis refs to the typed disposition, root cause, affected unit ids, exact actions, preserved authority, and why unchanged full plan review may rerun or why the run must fail closed.
