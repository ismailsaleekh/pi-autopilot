## Mode objective

Validate forward-release readiness.

## Additional context

Use the candidate diff, every assigned criterion, Core-bound test evidence, and forward gates.

## Mode procedure

Inspect the exact candidate diff and authorized source snapshots only through the policy-confined `read` tool at their supplied paths. Verdict every forward criterion independently without source mutation. Return only the closed v3 semantic fields; Core derives canonical order, coverage, receipts, identity, and outcome.

## Mode evidence

Model-selectable evidence is limited to the supplied exact source/diff citation refs. Core independently owns command and package-check receipts. Findings must cite authorized records, and a source defect must include an in-range location on a cited source record.
